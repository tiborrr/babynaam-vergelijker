# Agent Guidelines

## UI Design: Singular Controls (No Redundant UI)
- **One control per user intent:** Never provide multiple buttons or controls for the exact same action within the same view or screen (e.g., avoid having both an inline button and a standalone button performing the same action).
- **Consolidate, don't accumulate:** When introducing a clearer or more prominent action button, always prune or remove any existing duplicate controls rather than keeping both.
- **Clean dividers:** Keep visual dividers and spacers purely informational without embedding redundant action buttons.
